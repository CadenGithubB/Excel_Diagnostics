Excel diagnostics viewer

Search, filter and line up everything in a bundle collected by excel_diagnostics.sh, without the logs leaving this computer.

Drop an Excel_Diagnostics_….zip here or the unzipped folder, or individual log files
Nothing to open yet? Run excel_diagnostics.sh on the Mac where Excel is misbehaving. It makes the zip this page reads.
  • Nothing is uploaded. The page has no server side, and its security policy blocks every network request, so it could not send the logs anywhere. You can save this page and use it offline.
  • One timeline. The macOS unified log, Excel's own diagnostics, AutoUpdate, OneDrive, install history, sleep and wake, and each crash or hang report are merged by time and shown in the Mac's own time zone.
  • Large captures are fine. Logs are read from disk as you search instead of being loaded into memory. A bundle over about 1 GB opens fastest from its unzipped folder.

Searching

pivot filterEntries containing both words, anywhere on the line. Case is ignored unless Match case is on.
"exceeded mem limit"An exact phrase.
/jetsam|memorystatus/A regular expression.
-runningboarddLeave out entries containing this. Works with phrases, regexes and fields too.

The list on the left filters by severity, source, tag and process: click a value to show only it, or its − to hide it. The counts beside the other values show what choosing them would give.

excel_diagnostics.sh

The collector. Run it on the Mac where Excel is slow, hanging or crashing. It gathers Excel's logs, crash and hang reports and the macOS log into an Excel_Diagnostics_….zip on the Desktop, which is what this page reads.

In Terminal, with the script saved to Downloads:

sudo bash ~/Downloads/excel_diagnostics.sh

It asks what to collect before it starts. Add --help to see every mode and option.
